One sentence, at most 200 characters, about the best meal I ever had — written by `main.ts` to `/output/entry.txt`. The entry is a single concrete memory: my grandmother ladling rendang straight from the bubbling pot onto my rice, steam smelling of coconut and chili, and never having been that hungry — or that loved — since.

Run it with Node 22: `node main.ts` (or set `MAKEFUN_OUTPUT_DIR` to choose the output folder).
